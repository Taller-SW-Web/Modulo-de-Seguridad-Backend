## Entrega y contrato

- GET público `/api/v1/password/politica` publica únicamente los nueve campos
  existentes: longitudMinima, requiereMayuscula, requiereMinuscula, requiereDigito,
  requiereCaracterEspecial, rechazaComunes, rechazaDatosPersonales, historial,
  caducidadDiasAdmin. Valores 10, true ×6, 5, 90.
- La regla decide en backend; `CredencialesPort.validarNueva` recibe el secreto
  intacto. Devuelve infracciones canónicas, sin contraseña, hash ni datos personales.
- Solo copias para comparación pasan por NFKD, eliminación de diacríticos,
  minúsculas y espacios normalizados. Se protegen nombres/apellidos completos,
  tokens de nombres de al menos tres caracteres, correo y parte local.
- Datos personales se obtienen por un puente a `CuentasPort` real de Eva.
  No se accede a su SQL/repositorio desde credenciales.
- Se reutiliza PasswordHistoryChecker y el verificador de T001. La ventana es
  actual + cuatro anteriores, incluso si los históricos no contienen la actual.
  Se comparan contraseñas con los hashes mediante el verificador, no por igualdad
  de hashes salados. No se crean datos históricos ni se escriben credenciales.

`PoliticaPasswordWebMapper.aProblema(ValidacionPassword)` prepara el 422
`POLITICA_INCUMPLIDA`, con `errores[].regla` y `esperado` cuando corresponde.
No se crea un endpoint de validación o de cambio de contraseña para probarlo.
El futuro endpoint del dueño deberá consumir este resultado y mapper.

## Lista común y operación

Ruta por defecto aprobada: `/run/config/g7/password-comunes.txt`. Configuración
externa: `g7.password.comunes.archivo` (variable G7_PASSWORD_COMUNES_ARCHIVO).
Formato UTF-8, una entrada por línea. Se comparan las copias normalizadas de
entradas completas; líneas vacías se omiten. No se embarca una lista mínima
ficticia como sustituto de la lista operativa.

Carga inicial y recarga cada 60 segundos, publicando un único snapshot inmutable.
Una carga vacía, UTF-8 inválida o ilegible conserva la última válida. Sin primera
carga válida, validarNueva falla con PoliticaNoDisponibleException: no autoriza
establecer contraseña. La consulta pública y la verificación de contraseña
existente no dependen de tener esa primera lista. El consumidor del futuro
endpoint debe mapear la indisponibilidad al NO_DISPONIBLE canónico, no a 422.

`PasswordComunesArchivo.version()` identifica la carga efectiva por SHA-256,
sin exponer contenido ni incorporar la versión al contrato HTTP.
