## Contrato entregado al productor

Se conservan TokensUnUsoPort y los DTO propios de credencial.application.dto:

```java
Optional<TokenUnUsoSnapshot> localizar(String hash, PropositoToken proposito);
TokenEmitido emitir(UUID usuarioId, PropositoToken proposito, Duration ttl);
TokenEmitido emitir(UUID usuarioId, PropositoToken proposito, UUID contextoId, Duration ttl);
boolean consumir(UUID id, UUID usuarioId, PropositoToken proposito, Instant ahora);
boolean consumir(UUID id, UUID usuarioId, PropositoToken proposito, UUID contextoId, Instant ahora);
void invalidarPrevios(UUID usuarioId, PropositoToken proposito);
```

TokenUnUsoSnapshot: id, usuarioId, proposito, contextoId, expiraEn, creadoEn, usado. TokenEmitido: id, tokenClaro, expiraEn, con representación redactada.

DESBLOQUEO_AUTOMATICO requiere contextoId = revisión UUID real del bloqueo y TTL exacto 30 min. Genera 32 bytes aleatorios, retorna el valor claro únicamente al productor y persiste SHA-256. A igualdad con expiración no está vigente. Propósito, usuario o revisión distintos no consumen. Emisión invalida los enlaces vigentes anteriores del mismo usuario/propósito; el productor serializa por cuenta, no por IP.

Secuencia del productor: hash localiza orientativamente antes de locks; abrir escritura READ_COMMITTED; guard ADMIN → cuenta → bloqueo/racha → relectura del token → comprobar propósito/usuario/revisión/vigencia/uso → consumir con contexto real → mutación y efectos críticos del productor → commit. El Instant para consumo se obtiene después de esperar los locks. El productor es dueño del bloqueo de cuenta y de sus efectos; este port no los suplanta. La búsqueda inicial nunca autoriza por sí misma ni consume el enlace.
